# Insightful Search

Build a minimalist document semantic-search interface. The user should be able to: - upload a PDF or TXT file - see the filename after upload - see how many chunks were indexed - type a question about the document - press Search - see the most relevant document chunk - see the similarity score Do not implement backend functionality. Use mock data only where necessary. - use the image i gave you as reference of the interface, also make sure that the you use a soft gradient --purple: #E7B5EA; --red: #E25B4D; --orange: #F4A955; - very soft , dotn make it generic, it should feel minimalistic, minimum details and buttons - dont use a generic font
